# tp1
Trabalho de grupo 1 de ambientes
# Funcionalidades

- **dump** → Exporta N os empregos devolvidos pela API para um ficheiro JSON.
- **top** → Lista os N trabalhos mais recentes (com opção de exportar para CSV).
- **search** → Pesquisa trabalhos part-time por empresa e localidade.
- **jobtype** → Identifica o regime de trabalho (remoto, híbrido, presencial, outro).
- **skills** → Conta ocorrências de skills nas descrições dos anúncios entre duas datas.

# TP2
Trabalho de grupo 2

# Funcionalidades

- **get** → Obtém informação detalhada a partir do Teamlyzer de um emprego pelo seu id (rating, descricao, beneficios, salario medio), com opcao de exportar para csv
- **statistics** → Cria estatísticas de vagas por zona e posição
- **list skills** → Lista as top 10 skills associadas a uma profissão no Teamlyzer, com opção de exportar para CSV
